# 工作对话拓扑与应用恢复

通用规则见 [项目规范](PROJECT_RULES.md)；环境取值与命令见 [部署说明](DEPLOYMENT.md)。

一个项目对应一个 Codex workspace、多个归属该 workspace 的 Codex 对话和一个 GPT 对话；GPT 对话名称必须与 workspace 项目同名。新项目成套新建，执行在 Codex，GPT 只沟通和生成工程 Prompt。登记文本不能替代适配器独立验证实际会话。

恢复顺序：检测应用异常并区分确定退出与未知 → 报备用户 → 获事件绑定授权 → 按统一部署配置恢复应用 → 使用应用所在系统的解释器校验调试接口 → 恢复原项目会话映射与名称 → 重新验证 Prompt 来源后继续工作。

调试接口不可达不单独证明闪退，不能重启仍在运行或状态未知的应用。不终止进程，不抢焦点，不导出认证秘密。接口可达不证明模型、登录或任务已完成；会话不匹配保持阻塞，不重复发送不确定投递。跨操作系统子环境的回环网络不保证相通。

实现由可信宿主注入探测、报备、恢复和映射回调；默认命令行仅诊断。生产模型能力及真实应用恢复适配器仍须验证，Mock 测试只证明规则顺序与默认授权保护。
